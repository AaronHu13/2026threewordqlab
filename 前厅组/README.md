# 前厅组工作指南

喜剧节演出三个晚上，前厅组负责检票和引导观众入场。本文档是给前厅组工作人员看的操作说明。

## 一、当晚时间线

| 时间 | 事项 |
|---|---|
| 6:30 | 检票开始 |
| 6:45 | 最晚检票开始时间（无论前面有没有别的安排，6:45 必须开始检票） |
| 7:00 | 演出开始，播放花絮 / 开场视频 |
| 7:15 | 第一部剧正式开始 |
| 7:15 之后 | 前厅组不能马上撤，需留守一段时间，处理迟到观众的检票和引导 |

## 二、人员安排

- **每晚至少 2 名前厅组成员**，分别负责剧院左侧、右侧。
- 检票时，可以把排队观众分成两列（对应左右两个入口），减少拥堵、加快检票速度。
- 6:45 之后仍有观众陆续抵达属正常情况，负责检票的人员留守到人流基本结束、第一部剧开始后一段时间再离开岗位。

## 三、职责

1. **检票**：用 Eventbrite 的 **Organizer App** 扫票 / 核销。
2. **引导观众入场**：按下方"左右分流"的规则，把观众指引到正确的门。

## 四、剧院座位与门的对应关系（KPC · Kirkland Performing Center）

剧院左右两侧各有一扇门，观众从两侧门进场。

- **排号**：离舞台最近的一排是 **A 排**（22 座），离左右两侧门最近、离舞台最远的一排是 **L 排**（42 座）。
- **座号**：从左侧门进去后第一个座位是 1 号，1 号座位在**面朝舞台方向的左侧**；从左往右，座号依次增大。

### 左右分流原则

**座位号偏左（数字小）的观众走左门，座位号偏右（数字大）的观众走右门。**

- 每排座位号大致对半分：前半段（数字较小）从左门进，后半段（数字较大）从右门进。
- 例如 A 排 22 座，大致 1–11 号从左门进，12–22 号从右门进；L 排 42 座，大致 1–21 号从左门进，22–42 号从右门进（具体分界以现场引导为准，遇到犹豫不决的观众直接目测哪边近就往哪边引导即可，不用精确到某一个座位号）。
- 目的是让观众尽量从离自己座位更近的一侧入场、减少剧场内部横向穿行。

## 五、演出开始后的检票 / 引导

- 7:15 第一部剧开始后，仍会有迟到观众陆续抵达。
- 留守的前厅组人员继续给迟到观众检票，并按上面"左右分流"的原则引导他们从就近的门轻声入场，尽量避免打扰已经开始的演出。
- 迟到观众较多、剧场内已经暗场时，提醒他们放轻脚步、必要时可先在门口稍等一个自然的暂停点（如一段音乐/掌声之间）再引导入座。
